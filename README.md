# Visual Timer

## Overview

Visual Timer is a web-based countdown timer built using HTML, CSS, and JavaScript. It provides a visual representation of the remaining time along with customizable themes, accent colors, and audio notifications.

## Features

- Set countdown timer (hours and minutes)
- Visual circular timer
- Pause, resume, and reset controls
- Light/Dark mode
- Custom accent color selection
- Sound notifications with mute option
- Responsive and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Usage

1. Open `index.html` in a web browser.
2. Enter the desired time.
3. Click **Start** to begin the countdown.
4. Use **Pause**, **Resume**, or **Reset** as needed.
5. Customize the theme and accent color using the controls provided.
